이 디렉터리에는 사람이 작성하는 "도메인 지식"을 Markdown(.md) 파일로 둡니다.
여기 있는 모든 .md 파일은 비교 분석 시 LLM 프롬프트에 '참고 자료'로 항상 주입됩니다.
(이 README.txt 는 .md 가 아니므로 주입되지 않습니다.)

목적
- LLM 은 사내 용어·암묵지를 모르므로 내용 비교에서 오판할 수 있습니다.
- 사람이 배경지식을 정리해 두면, 용어·동의어·표기 규칙을 더 정확히 해석합니다.

작성 권장 구조 (예: domain.md)
--------------------------------------------------
# 용어 정의
- formation: 배터리 화성(formation) 공정을 의미한다.

# 동의어 / 표기 규칙
- "매출"과 "Revenue"는 같은 항목으로 취급한다.

# 비교 분석 실패 케이스
- 단위가 'k원'과 '천원'으로 달라도 값이 같으면 같은 것으로 본다.

# 기타 배경지식
- (자유 서술)
--------------------------------------------------

비교에서 특정 컬럼 제외하기
- .md 에 '제외'(또는 무시/exclude/skip 등) 키워드와 함께 컬럼명을 적으면, 그 컬럼은
  비교(판정)에서 자동으로 빠집니다. 두 형식 모두 인식합니다.

  (A) 섹션형 — 권장
      # 비교 제외 항목(컬럼)
      - 순번
      - 중분류 CODE, 소분류 CODE

  (B) 한 줄형
      - 순번, 중분류 CODE, 소분류 CODE 는 비교에서 제외한다.

- 애매한 표기도 됩니다: 적은 이름을 LLM 이 실제 엑셀 헤더에 매칭합니다.
    · 오타        '중분류 CODD'  → '중분류 CODE'     (LLM 필요)
    · 부분명칭    '중분류'       → '항목>중분류'      (멀티헤더 leaf, LLM 불필요)
    · 동의어      '코드'         → '중분류 CODE'      (LLM 필요)
    · 대소문자/공백 '중분류 code' → '중분류 CODE'      (LLM 불필요)
- 여러 개는 쉼표(,)·슬래시(/)로 구분하세요.
- 명확히 일치하는 헤더가 없으면 일부러 제외하지 않습니다(엉뚱한 컬럼 보호).
- 무엇이 빠졌는지는 실행 로그의 '[Excel] 지식 기반 제외 컬럼: [...]' 로 확인합니다.

주의
- 이 지식은 '배경 설명'일 뿐입니다. 대상 문서에 실제로 없는 내용을 '있다'고
  판단하는 근거로는 쓰이지 않도록 프롬프트에서 한 번 더 제한합니다.
