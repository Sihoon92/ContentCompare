이 디렉터리에는 사람이 작성하는 "도메인 지식"을 Markdown(.md) 파일로 둡니다.
여기 있는 모든 .md 파일은 비교 분석 시 LLM 프롬프트에 '참고 자료'로 항상 주입됩니다.
(이 README.txt 는 .md 가 아니므로 주입되지 않습니다.)

목적
- LLM 은 사내 용어·암묵지를 모르므로 내용 비교에서 오판할 수 있습니다.
- 사람이 배경지식을 정리해 두면, 용어·동의어·표기 규칙을 더 정확히 해석합니다.

작성 권장 구조 (예: domain.md)
--------------------------------------------------
# 용어 정의
- formation: 배터리 화성(formation) 공정을 의미한다.

# 동의어 / 표기 규칙
- "매출"과 "Revenue"는 같은 항목으로 취급한다.

# 비교 분석 실패 케이스
- 단위가 'k원'과 '천원'으로 달라도 값이 같으면 같은 것으로 본다.
